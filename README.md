## O tomhle repozitáři

Zdrojový kód mého portfolia **[pajinell.cz](https://pajinell.cz)** — statický web, čisté HTML + CSS bez frameworku (styly i skripty jsou přímo v `index.html`).

### Nasazení

- Web nasazuje **Netlify**
- Netlify sleduje větev `main` — po každém pushi se web automaticky nasadí na `pajinell.cz`.
- Žádný build krok není potřeba, nasazuje se přímo obsah repozitáře.

### Verze webu

- `/` — aktuální design „Dichroic“ (tečkované plátno, dichroické barvy)
- `/old2` → [pajinell.cz/old2](https://pajinell.cz/old2) — předchozí verze (mauve, light/dark)
- `/old` → [pajinell.cz/old](https://pajinell.cz/old) — původní web

### Struktura

- `index.html` — jednostránkové portfolio (hero, o mně, projekty, detail projektu)
- `live-jizda-*.png`, `onboarding-*.png` — obrázky v detailech projektů
- `selfie.jpg` — fotka v záložce editoru
- `favicon.*`, `android-chrome-*`, `apple-touch-icon.png`, `site.webmanifest` — ikony
- `ukazka-feature-info/` + `feature-info.png` — samostatná ukázka kódu
